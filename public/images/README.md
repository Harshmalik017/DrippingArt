# Product images go here

Drop your photos into this folder using these exact filenames and the
gallery on the homepage will pick them up automatically:

- wall-clock-1.jpg
- keychain-1.jpg
- photo-frame-1.jpg
- nameplate-1.jpg
- coaster-1.jpg
- tray-1.jpg

Until a file exists, that gallery tile shows a soft "Photo coming soon"
placeholder instead of a broken image, so the site is safe to deploy
before you've added photos.

Want different names, more photos per category, or a different order?
Edit `lib/products.ts` — each entry is just a name, category, image path
and accent colour.
